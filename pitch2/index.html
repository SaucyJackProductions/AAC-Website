03 · Pixel and tracking

Setting up the pixel, explained.

Before a dollar goes to ads, we install tracking so every visit, inquiry, call and tour is counted. Pick something a visitor does to see what fires and what it unlocks.

Ownership first

Meta Business Manager, ad account, Google Ads and GA4 created in the club's name. Woodcreek owns the data if we ever part ways.

Pixel + Conversions API

Meta Pixel in the browser plus server-side Conversions API through Google Tag Manager, with matching event IDs so nothing double counts.

Verify and rank

Verify woodcreekclub.com in Meta, rank events (Lead, Schedule, Contact) and turn on Google enhanced conversions.

Consent and privacy

Cookie banner, updated privacy policy, and member lists uploaded only in hashed form.

Audiences

Site visitors, membership-page viewers and tournament fans for retargeting. Current members excluded. Lookalikes built from the best leads.

One dashboard

Leads, tours, cost per lead and new members in a monthly report the GM can read in two minutes.
